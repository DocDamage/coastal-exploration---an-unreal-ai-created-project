## Integration and fixes

The new original plugin implements a bounded M1 codec for the authored battery and fuse, fixed backpack/storage grids, placement/rotation and canonical receipts. Transactions construct and validate temporary real AGIS components before swapping their native container/cache properties into stable live AGIS components under a game-thread guard. No vendor GameInstance save system, vendor inventory UI or second live inventory is installed. The real AGIS partial-add API is not treated as atomic. Future or foreign provider versions are reported as incompatible to protect their disk slots; transfer receipts without a prior pickup are rejected. Item definitions are original transient parent rows attached to the installed composite table; vendor assets on disk remain unchanged.

Hyper's focus component is attached to the character. Its original child suppresses demo startup/input timers; the host explicitly evaluates the real vendor trace. Native Enhanced Input owns E / gamepad FaceLeft. The existing relay publishes offers into Hyper's widget. The vendor's fixed A image is hidden and the actual E / gamepad X bindings appear in that same prompt. Automatic device-specific glyph selection is not implemented.

One controller host component waits for possession/player input and calls the existing session bootstrap once. The existing UI, coordinator, mission and recovery components retain their ownership. The integrated room is `/Game/Coastal/Maps/L_SystemsTest_Integrated`; prior smoke and partial maps are preserved.

Native compilation fixes from the initial pass are retained. A real rendered-menu crash exposed UE 5.7 EditableTextBox retaining a pointer to a temporary style; the panel now resynchronizes the widget-owned style. Fresh-process Continue exposed TeleportTo returning false for movement below the engine transform tolerance. Restore now recognizes an already matching, validated dry placement; real moves still require checked teleport and post-placement safety validation. Initial failures and rollback logs are preserved outside the public repository.
